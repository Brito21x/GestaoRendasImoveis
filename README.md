# 🏠 Gestão de Rendas de Imóveis (C#)

Projeto desenvolvido em **C#** no âmbito da unidade curricular de **Programação Orientada a Objetos**.

## 📚 Descrição

Este projeto implementa um sistema de **gestão de rendas de imóveis**, permitindo representar e organizar entidades como imóveis, inquilinos, senhorios, contratos e recibos.

O objetivo principal é aplicar conceitos fundamentais de **Programação Orientada a Objetos (POO)** através da modelação de um sistema real.

## 🧠 Conceitos Aplicados

- Classes e objetos  
- Encapsulamento  
- Herança (ex: `Pessoa` → `Inquilino` / `Senhorio`)  
- Organização modular do código  
- Separação de responsabilidades  

## 🧱 Estrutura do Projeto

Principais ficheiros e classes:

- `Program.cs` – Ponto de entrada da aplicação  
- `Pessoa.cs` – Classe base para entidades pessoais  
- `Inquilino.cs` – Representa um inquilino  
- `Senhorio.cs` – Representa um senhorio  
- `Imovel.cs` – Representa um imóvel  
- `Contrato.cs` – Gestão de contratos de arrendamento  
- `Renda.cs` – Informação sobre rendas  
- `Recibo.cs` – Emissão de recibos  

## ⚙️ Tecnologias

- C#  
- .NET 8.0  
- Visual Studio
